# Unreal-Platformer-Game
A game with portal aesthetics, platformer elements and puzzles to solve.
In the game player uses a gravity gun to scale, rotate, move or freeze objects around them to find the way out.
The level changes slightly every time the player reaches the exit and adds new mechanics.
